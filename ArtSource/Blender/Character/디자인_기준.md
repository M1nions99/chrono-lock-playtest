# 주인공 · 제작 기준

사용자 확정: 고유 이름 없이 **주인공**으로 표기. 짧은 머리의 성인 남성 탐사원. 현실적인 인체 비율에 형태를 정돈한 SF 게임풍.

전신과 손을 같은 인체 모델에서 제작한다. 어깨·팔꿈치·손목·손가락의 관절과 연결을 맞추고, 1인칭 오른팔은 같은 모델에서 파생한다. 눈을 뜨는 장면과 시간 능력 사용 장면에서도 같은 오른손을 사용한다.

의상 방향은 따뜻한 회백색과 흑연색의 기능성 탐사복, 제한적인 주황색 구분선, 관절의 유연한 천, 튼튼한 부츠다. 오른손은 맨손이며 손바닥 피부 위에 청록색 시간 문양이 있다. 손에 쥔 도구나 손목 기기는 없다.

산출물은 편집 가능한 Blender 전신 원본, Unity용 FBX, 재질, 관절 움직임 검증, 실제 모델을 렌더한 전면·후면·오른손 이미지다. 콘셉트 이미지는 외형의 참고 자료이며 완성 모델 렌더와 구분한다.
