# 주인공 모델 사용 안내

**짧은 머리의 성인 남성 탐사자**, 현실적인 체비율의 SF 게임풍 전신 1차 모델입니다. 표시 이름은 **주인공**입니다. 작업복은 배경 설정에 맞춘 복장이며 별도의 능력·장비 기믹은 없습니다. 시간 능력의 표현은 **오른손 문양**입니다.

## 현재 완성 범위

- 전신 메시·재질·텍스처와 오른손 문양, 53개 본의 리그.
- Unity Generic 리그 가져오기와 약 1.78m 기준 프리팹 크기 검증.
- 전용 캐릭터 미리보기 씬과 Blender 실제 모델 렌더.

**추가 적용 완료:** 같은 모델의 오른팔을 기존 게임의 시작 연출과 실제 1인칭 플레이에 연결했습니다. 능력 적용 시 팔 들기·손가락 움직임·문양 색 변화가 작동합니다. 전신 보행·얼굴 연기 애니메이션, 별도 애니메이션 클립 및 새 실행파일 배포는 아직 완료하지 않았습니다.

## Blender에서 열기

현재 모델 원본은 [Protagonist.blend](Protagonist.blend)입니다. [Protagonist.fbx](Protagonist.fbx)는 Unity 가져오기용 파일입니다. 텍스처 폴더와 함께 보관하세요.

원본 프로젝트의 반영 경로는 다음과 같습니다.

`C:/Users/bhb41/Desktop/5team/5team/ArtSource/Blender/Character/Protagonist.blend`

Blender 원본과 텍스처, Unity FBX·재질·프리팹·미리보기 씬을 위 프로젝트에 저장했습니다. 복사한 파일은 원본과 SHA-256 값이 같은지 확인했습니다.

Blender 파일에는 작업에 사용한 **숨겨진 원본 인체와 렌더용 스튜디오**도 들어 있습니다. 비교·후속 편집용이므로 숨긴 원본을 최종 의상 모델과 동시에 표시하지 마세요. Unity FBX에는 표시용 모델만 내보냈으며 원본 인체·스튜디오는 포함하지 않습니다.

## Unity에서 확인

Unity 상단 **ChronoLock > Open Character Preview**를 선택하세요.

- 캐릭터 프리팹: `Assets/ChronoLock/Resources/Protagonist.prefab`
- 미리보기 씬: `Assets/ChronoLock/Scenes/ChronoCharacterPreview.unity`

전용 미리보기는 모델 확인용입니다. 이 씬을 열었다고 기존 방탈출 플레이어가 새 전신 모델로 자동 교체되지는 않습니다. FBX 루트의 축 보정은 유지하고 감싸는 루트로 크기를 조절하도록 가져오기 처리가 되어 있습니다.

## 검증 메모

Generic 리그 가져오기, 프리팹 크기와 메시·재질 참조 검사, 오른손 손가락 일부의 굽힘 검사를 확인했습니다. 검증 프로젝트에서 생성된 프리팹은 높이 1.7800m, 렌더러 43개, 재질 슬롯 44개로 보고되었습니다. 이후 오른팔 게임 연결, 메뉴 전환, 시작 연출·건너뛰기, 시야각 60/78/100, 세 능력 반응과 기존 탈출 경로를 검증했습니다. 상세 자료는 프로젝트의 Docs/ChronoLock/주인공_1인칭적용 폴더에 있습니다.
