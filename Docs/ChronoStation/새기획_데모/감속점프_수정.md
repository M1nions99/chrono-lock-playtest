# 감속 점프 높이 수정 — 2026-09-16

문제: 점프 초기 속도는 6.2로 유지하면서 감속 중력만 20에서 2.8로 낮췄습니다. 그 결과 이론상 점프 높이까지 약 7.14배 커졌습니다.

수정: 같은 수직 궤적을 느린 시간으로 진행하도록 변경했습니다. 공중에서 감속을 켜거나 해제·만료해도 내부 기준 속도를 다시 키우지 않습니다. 낙하 속도 제한과 천장 충돌 처리는 유지합니다. 튜토리얼 도움말에도 점프 높이는 같다는 설명을 추가했습니다.

실제 CharacterController와 기존 방 바닥에서 30/60/120Hz 시간 간격으로 검사했습니다. 일반, 감속 선사용, 상승 중 사용, 상승 중 해제, 상승 중 만료의 15가지 경우를 확인했습니다.

- 측정한 최고 높이: 약 0.952~0.961m. 일반·감속 간 차이는 1cm 이내였습니다.
- 일반 점프 체공시간: 약 0.625~0.633초.
- 감속 점프 체공시간: 약 3.109~3.133초.
- 감속 튜토리얼의 8m 틈과 이동 발판을 포함한 8단계 전체 경로 자동 완주 검사 통과.

이는 Unity 자동 시뮬레이션 측정이며 사람의 입력 검증이나 렌더링 FPS 측정과는 다릅니다. 자세한 수치는 jump-result.txt에 저장했습니다.
