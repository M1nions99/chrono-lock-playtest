# 자기·사물 직접 조작 개선

2026-09-16

대상을 별도 키로 전환한 다음 능력을 쓰던 단계를 없앴습니다. 능력을 선택한 뒤 마우스 버튼으로 적용 대상을 바로 정합니다.

| 입력 | 동작 |
|---|---|
| 우클릭 | 자기 자신에게 적용 |
| 좌클릭 | 조준한 사물에 적용 |
| 휠 / 1~4 | 해금된 능력 순환 / 직접 선택 |
| Q | 자기·사물 효과 모두 해제 |

같은 대상에 같은 능력을 다시 누르면 해당 효과를 해제합니다. 자기 정지는 능력 선택을 바꿨더라도 우클릭으로 풀 수 있습니다. 자기 되감기는 짧은 재시도 연출이 끝날 때까지 진행됩니다.

사물과 자기 효과는 함께 유지할 수 있습니다. 빈 공간에 좌클릭하면 자신에게 잘못 적용되지 않습니다. 처음 네 구역에서는 사물 조작이 잠겨 있고, 이후 해금됩니다. 화면 아래에 두 버튼의 역할, 오른쪽 위에 자기·사물의 현재 효과를 따로 표시합니다. 조작법 메뉴와 모든 단계의 안내도 갱신했습니다.

## 검증

- Unity Input System에 가상 마우스·키보드 상태를 전달하고 실제 게임 입력 처리로 34개 조건을 검사했습니다. 해금, 휠 순환, 자기·사물 동시 적용, 같은 버튼 재입력 해제, Q 전체 해제, 빈 공간 클릭, 일시정지 및 재개 입력을 통과했습니다.
- 실제 캐릭터 이동과 장치 조준으로 8단계 전체 경로를 완주하는 자동 검사를 통과했습니다.
- 메뉴, 설정 저장·취소, 16:9 / 16:10 화면 배치 검사를 통과했습니다.
- 감속 점프는 30/60/120Hz에서 켜기·해제·만료를 포함한 15개 조건을 검사했습니다. 일반 점프와 감속 점프의 최고 높이 차이는 1cm 미만입니다.

## Claude 검토 판단

Claude는 직접 적용·해제 로직에서 모순을 찾지 않았습니다. 선택 함수 자체에 메뉴 상태 검사가 없다는 방어적 개선 제안도 검토했습니다. 현재 키보드와 휠은 게임 입력 진입점에서 차단되며, 메뉴 전환 시 기존 HUD를 즉시 비활성화하고 선택된 UI를 해제합니다. 각성 중 능력 버튼도 비활성화합니다. 현재 연결된 입력 경로에서 재현되는 결함으로 판단하지 않았으며, 일시정지 중 버튼·휠·숫자 입력이 선택과 효과를 바꾸지 않는 것을 실제 입력 검사로 확인했습니다. 향후 외부 입력 경로를 추가할 때 다시 검토할 수 있습니다.
