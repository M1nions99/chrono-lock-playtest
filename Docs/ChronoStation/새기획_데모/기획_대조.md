## 기존 되감기의 정확한 현재 상태

현재 `TemporalDevice.cs`는 `Normal / Freeze / Accelerate / Rewind`를 정의합니다. Normal은 기본 진행 상태이므로, **사용 능력은 정지·가속·되감기 3종**입니다. 감속 능력은 없습니다.

되감기는 단순히 현재 값에서 목표 값까지 보간하는 코드만으로 구성되어 있지 않습니다.

- `List<float> history`에 장치의 단일 `state`를 30Hz로 기록합니다. 최대 241개이며 표시 가능한 기록 길이는 최대 약 8초입니다.
- 되감기는 고정 스텝마다 최신 기록을 최대 2개 제거하고 남은 마지막 값을 적용합니다. 기록이 충분할 때 약 2배속으로 과거 상태를 소비합니다.
- 회전 장치의 상태는 각도, 발전기의 상태는 충전량입니다. 화면 표현은 이 값을 회전 또는 크기로 변환합니다.
- 다리는 시작 시 0부터 1까지 121개 값을 넣어 **미리 작성한 4초 붕괴 기록**을 구성합니다. 플레이 도중 실제 붕괴 물리를 관측·녹화한 기록이 아닙니다. 다리 위치는 복구 위치에 손상 오프셋 × 상태를 더해 계산합니다.
- 되감기 후 정상 진행하는 회전 장치·발전기는 복원된 상태부터 새 기록을 만듭니다. 다리는 정상 진행 중 새 기록을 추가하지 않습니다.
- 플레이어 위치·체력·목표 진행·경과 시간은 이 장치 기록에 포함되지 않습니다. 자유로운 물체의 위치·회전·선속도·각속도·충돌·파괴 상태를 함께 복원하는 일반 기록기는 아닙니다.

따라서 정확한 표현은 **“제한된 장치 상태 기록·역재생은 기존 구현에 존재하며, 새 기획의 일반 물체 운동 역재생은 별도 설계·구현이 필요하다”**입니다. 물체가 기록 이전 시점으로도 돌아가는지, 파괴/소모를 어떤 상태로 저장할지는 아직 정해지지 않았습니다.

## 확정된 요구와 미정 항목

### 이번 사용자 설명에서 확인된 방향

- 시작 시 능력 대상은 자기 자신입니다.
- 가속은 자기 이동속도 증가, 감속은 자기 이동속도 감소와 공중 체공, 정지는 자기 피해 방어라는 효과를 구분합니다.
- 물체 대상에서는 가속·감속·정지·과거 운동 역재생의 4종 효과를 구분합니다.
- 최초 자기 되감기는 “스테이지 재시작?”으로 제시되었습니다. 이후 제작 방향은 현재 구역 입구로 재시도하는 효과로 안내되었으며, 실제 구현·검증 완료와 구분합니다.

### 확정 이후 구체화·검증할 항목

1. **범위는 확정:** 자기 대상 4종 학습 이후 사물 조작 해금. 연구실 → 연결 통로 → 도킹의 3구역, 8단계 퍼즐은 개발 계획이며 아직 완료 보고가 아닙니다. 각 단계 완료 조건은 구현·검증에서 구체화합니다.
2. **자기 되감기 제작 방향:** 현재 구역 입구 재시도. 재시도 시 해당 구역의 어떤 기믹 상태를 초기화하는지, 이전 구역 진행을 유지하는지는 구현 규칙으로 명확히 해야 합니다.
3. **자기 효과의 세부 규칙:** 가속·감속 배율, 체공의 시작·종료 조건, 정지 방어의 대상 피해·지속시간·이동 가능 여부.
4. **물체 능력 해금:** 자기 대상 4종을 학습한 뒤 해금하는 순서는 확정입니다. 해금 전 필수 사물 퍼즐로 진행이 막히지 않는지 검증해야 합니다.
5. **되감기 기록 범위:** 기록 길이·재생 속도·기록 소진 시 동작·재생 종료 후 속도·파괴/소모 복원 범위.
6. **표현과 명칭:** CHRONO STATION 적용 여부, 특수 장치와 기존 오른손 문양의 관계.
7. **제한시간:** 카운트다운의 실제 적용 여부와 실패 조건. 목표 플레이 시간 20~30분은 테스트 전 달성으로 표기하지 않습니다.

## 새 데모 작업본 현황 (실행 검증 전)

새 `StationGame`과 `StationUI` 작업본이 작성되었습니다. 기존 CHRONO LOCK의 구현 현황과 혼동하지 않도록 별도 작업본 기준으로 기록합니다.

- 자기 가속·감속·정지·되감기 학습 후 사물 조작을 해금하는 8단계 흐름을 코드에 구성했습니다. 자기 되감기는 관측 기록을 유지하고 현재 구역 입구로 돌아오는 방향입니다.
- 타이틀은 CHRONO STATION이며 새 게임·이번 실행의 이어하기·설정·조작법을 제공합니다. 이어하기는 종료 후 저장 데이터 복원을 뜻하지 않습니다.
- HUD는 현재 목표, 능력 해금·선택, 자기 능력 잔여 시간과 재사용 대기를 표시합니다. 자세한 도움말은 H로 확인하며 오프닝 건너뛰기는 Enter로 안내합니다.
- 설정은 적용 및 저장을 눌렀을 때 실제 환경설정에 반영하며, 돌아가기에서는 미적용 변경을 폐기합니다.
- 이는 소스 작성 및 API 대조 현황입니다. Unity 컴파일, 실제 조작, 화면 가독성, 퍼즐 전체 완주 또는 사물 이력 재생 검증 완료를 주장하지 않습니다. 20~30분 목표도 실측 전입니다.
