# 주인공 오른팔 · Unity 적용

원본 프로젝트 `C:/Users/bhb41/Desktop/5team/5team`에 새 주인공의 오른손과 소매를 연결했습니다.

Unity 상단 **ChronoLock → Open Research Station**을 선택한 뒤 **Play → 이야기 시작**으로 확인하세요. 이미 Play 중이었다면 정지 후 다시 시작하세요.

- 기존 손목 기기와 별도로 등장하던 오프닝 손을 교체했습니다.
- 같은 오른팔이 깨어나는 장면과 실제 플레이에 사용됩니다. 손가락은 주인공의 원래 관절로 움직입니다.
- 평소에는 오른손을 아래로 내리고, 장치에 능력을 적용하면 들어 올립니다. 정지는 청록, 가속은 주황, 되감기는 보라색 문양으로 표시됩니다.
- 타이틀·일시정지·결과 화면에서는 손과 손 전용 카메라를 숨깁니다. 손에는 충돌체가 없어 장치 조준을 막지 않습니다.
- 시야각 60/78/100과 카메라 움직임 끄기를 확인했습니다.

## 파일

- 전신 Blender 원본: `ArtSource/Blender/Character/Protagonist.blend`
- 전신 Unity 프리팹: `Assets/ChronoLock/Resources/Protagonist.prefab`
- 실제 게임 오른팔: `Assets/ChronoLock/Resources/ProtagonistRightArm.prefab`
- 추출 메시: `Assets/ChronoLock/Art/Character/FirstPerson/`
- 실제 게임 씬: `Assets/ChronoLock/Scenes/ChronoLab.unity`

오른팔은 전신의 메시·UV·재질·관절 가중치를 그대로 추출한 자산입니다. 전신을 수정한 뒤에는 `ChronoLock → Open Character Preview`, 이어서 `ChronoLock → Build First Person Right Arm`으로 다시 가져오세요.

## 확인한 범위

시작 연출의 자연 종료, 눈뜨기·손 확인·일어서기 단계에서 건너뛰기, 일시정지·메인 메뉴·이어하기, 손 중복 방지, 세 능력의 적용과 문양 색, 시야각과 정지 자세를 자동 Play Mode 검증했습니다. 기존 탈출 경로와 메뉴 검증도 통과했고 실제 카메라로 촬영한 화면을 확인했습니다.

검증은 게임의 실제 동작 API를 사용했습니다. 물리 키보드·마우스 입력을 대신 누른 검사는 아닙니다. 캡처는 검증용으로 Canvas 모드와 HDR/후처리를 잠시 바꾸므로 실제 화면과 일부 차이가 있습니다. 저장된 사용자 옵션은 변경하지 않았습니다.

이번 적용은 1인칭 오른팔과 관절 기반 동작입니다. 전신 보행·얼굴 연기 애니메이션, 별도 튜토리얼 개선본, 새 Windows 실행파일과 GitHub 배포는 이번 반영에 포함되지 않았습니다.
