# 시작 연출 · UI · 스토리 적용 결과

2026-09-15 기준. 최신 실행 파일은 Windows_최신판/ChronoLock.exe입니다. 원본 Unity 프로젝트에도 동일한 코드·씬·아트를 반영했습니다.

## 무엇이 달라졌나

기존에는 스토리 설명 뒤 바로 로터 앞에서 시작했습니다. 지금은 실제 구조실에 놓인 구조 침상에서 눈을 뜨고, 손바닥 앵커를 바라보며 이오의 구조 통신을 듣는 흐름입니다. 통신은 자막과 짧은 합성음이며 성우 음성은 아닙니다. 누운 카메라에서 일어나 같은 방의 자유 이동으로 이어집니다.

시작 공간에는 Blender 구조 침상, 빈 구조 유닛, 생체 상태 모니터, 블랙홀 관측창과 바닥 유도등을 배치했습니다. 기존 입구 벽을 출입구로 바꾸고 구조실을 연결했습니다. 로터·발전기·다리·에어록의 기존 퍼즐은 유지했습니다. 손 모델은 문양이 보이는 구조용 장갑 형태입니다.

블랙홀 관측실 타이틀, 일시정지 메뉴, 화면·조작·오디오·접근성 설정, 단계별 힌트, 발견 기록과 구간 통신 탭도 포함합니다. 전체 이야기는 5장으로 설계했고 현재 플레이는 1장입니다. draw.io 4페이지에는 게임 흐름, 개선 전후, 참고작과 향후 과제, 스토리 연결을 정리했습니다.

## 확인한 내용

- 실제 10.5초 각성 진행, 문양 모델 표시, 자연스러운 종료와 정상 시점 복귀.
- 각성 중 일시정지·타이틀 복귀·이어하기, 세 단계 각각의 건너뛰기, 빠른 재시작.
- 카메라 움직임 효과를 끈 고정 시점, 조작이 시작된 이후의 플레이 타이머.
- 구조실에서 복도로 이동한 뒤 정지·가속·되감기·에어록 탈출까지의 전체 경로.
- 설정 적용·취소·저장/로드, 마우스 이벤트 경로를 통한 슬라이더 이동, 메뉴 복귀, 기록 해제.
- 화면 검사에서 텍스트 높이 초과 경고 없음. 16:9·4:3·울트라와이드 타이틀 배치도 확인.
- Windows 빌드 성공. 배포한 실행 코드·리소스·씬 파일의 해시가 빌드 원본과 일치.

검사 중 카메라 조준선이 자기 CharacterController에 먼저 닿는 간헐 오류를 발견했습니다. 플레이어를 기본 조준선에서 제외하고, 물리 충돌과 벽 가림은 유지했습니다. 수정 후 전체 이동·퍼즐 검사가 통과했습니다.

## 검증 범위

연출과 퍼즐 검사는 Unity Play Mode에서 실제 시간을 진행하고 게임의 동작을 호출해 검사했습니다. 전체 탈출을 사람이 키보드로 끝낸 시험으로 표현하지 않습니다. 메뉴의 마우스 선택·감도 드래그·변경 취소·이야기 시작 연결은 앞선 스토리 실행판에서 직접 확인했습니다.

최신 시작 연출의 별도 화면 조작 검증은 사용자의 물리 Escape 입력으로 중단했습니다. 이후 화면 제어는 재개하지 않았습니다. 최신판의 연출·동선·UI·빌드는 자동 실행 검사와 실제 카메라 렌더로 확인했습니다.

Claude Code의 실제 UI·스토리·각성 연출 정적 검토와 병렬 코드 검토를 함께 사용했습니다. 각성 검토에서 지적한 재개 직후 Space 잔여 입력을 차단했고, 연출 화면의 재시작 방어 조건도 보강했습니다. 후자는 현재 조작에서 도달하지 않는 경로의 예방 조치입니다. 두 조건 수정 후 연출 자동 검사와 Windows 빌드를 다시 통과했습니다. 전체 퍼즐·UI 검사는 두 입력 조건 수정 전 동일한 씬·퍼즐·UI의 통과 결과입니다. 코드 리뷰는 실행 시험과 구분합니다. 원문은 Claude_시작연출_검토.md에 보관했습니다.
