## 현재 상태

Blender FBX 콘솔·발전기·벽 모듈, 별도 블랙홀 타이틀 배경과 구조 침상·손바닥 앵커를 적용했습니다. 현재 시작은 실제 구조실에서 약 10.5초간 눈뜨기·문양 확인·일어서기를 진행한 뒤 같은 방의 자유 이동으로 이어집니다. 기존 퍼즐은 그 뒤에 연결됩니다. 전체 스토리는 5장 설계, 플레이는 1장입니다.

UGUI 타이틀·일시정지·4탭 설정과 저장·단계별 힌트·발견 기록·구간 통신이 구현되어 있습니다. 새 여정은 각성부터 시작하고 빠른 재시작은 구조실에서 바로 시작합니다. 진행 중 여정은 실행 중에만 이어갈 수 있습니다. 설정과 최고 기록만 영구 저장됩니다.

Claude Code 실제 [각성 연출 검토](Claude_시작연출_검토.md)까지 반영했습니다. 재개 직후 Space 입력에는 InputReady를 적용했고 Awakening의 재시작 가드도 보강했습니다. 조준선이 자기 CharacterController를 맞히는 오류는 실제 진단 후 플레이어 Ignore Raycast 레이어로 수정했습니다. 최신 [검증 문서](시작연출_변경과_검증.md)를 기준으로 검토하세요.

로터 통과 시 `active` 참조 정리 누락을 수정했습니다. 포커스 상실 시 자동 일시정지는 의도이며 Esc는 일시정지 반환 조건 전에 처리됩니다. 마우스 delta에 deltaTime을 추가로 곱하지 마세요.

시간 능력은 선택한 장치 하나에만 작용합니다. 정지 0배 / 가속 4배 / 기록 되감기 2배이며 플레이어·경과 시간·완료 목표는 되감지 않습니다. 발전기의 정상 충전과 다리의 미리 기록된 사고 상태는 의도한 규칙입니다. 능력 구현에 전역 `Time.timeScale`을 사용하지 않습니다.

실제 Play Mode의 스크립트 이동·상호작용 API 전체 탈출 QA는 통과했습니다. 사람의 키보드·마우스 완주와는 구분하세요. 마지막 HUD·손목·로터 참조 수정 이후 **최종 Windows 빌드와 전체 경로 Play Mode 재검증도 통과**했습니다.

## 다음 교차 검토 프롬프트

> Assets/ChronoLock의 최신 Runtime과 Editor 파일, 검증 문서를 먼저 읽어줘. 파일은 수정하지 말고 실제 재현 가능한 진행 불가·입력·생명주기·시간 기록·재시작 오류를 우선 검토해줘. 재현 조건, 현재 파일/줄, 최소 수정안과 검증 방법을 제시해줘. 기존 Claude 리뷰의 결론도 현재 코드로 다시 확인해줘. 의도된 정상 충전·사고 기록·포커스 일시정지·Mouse.delta 처리를 버그로 재보고하지 말고, 코드로 반례가 확인될 때만 지적해줘. 자동 QA는 CharacterController 이동과 production API 검증이며 실제 하드웨어 입력이나 HUD 시각 검증은 아니라는 한계를 유지해줘.

## 병렬 작업 규칙

1. 시작 전에 변경 파일 담당을 나누고 공통 인터페이스를 합의합니다.
2. 같은 파일을 두 도구가 동시에 수정하지 않습니다.
3. 리뷰와 구현을 분리하고, 통합 담당이 재현 후 반영합니다.
4. Unity 컴파일·로직 검증·Play Mode 경로 검증 후 실제 조작과 화면을 확인합니다.

감도·볼륨·FOV 설정과 저장은 이미 구현되어 있습니다. 설정은 `ChronoPreferences`, 합성 오디오는 `ChronoFeedback`, 각성은 `ChronoOpening`을 먼저 확인하세요. 이전 실행판은 정리했으며 배포본은 `Windows_최신판` 하나입니다. 새 구역 제작 시 현재 시작 연출과 구조실을 덮어쓰지 마세요.
