# CHRONO / LOCK · 스토리 시작 연출 설계

**구현·검증 상태: 반영 완료.** 실제 Unity 구조실과 약 10.5초의 각성 연출을 원본 프로젝트·최신 실행판에 적용했다. 연출·동선·UI 자동 검증과 Windows 빌드가 통과했다. 아래는 적용 기준이며, 확인한 범위는 [변경과 검증](시작연출_변경과_검증.md)에 구분해 기록했다.

## 플레이어가 처음 보는 장면

타이틀의 **이야기 시작 / BEGIN STORY**를 누르면 긴 필수 설명 화면 대신 **구조 침상에 누운 1인칭 시점**으로 시작한다. 가까운 곳의 침상·의료 장치와 빛나는 손바닥 문양이 보여야 한다. 처음부터 멀리 있는 회전 로터가 화면의 중심이면 안 된다.

주인공은 구조된 사람이고 이오는 손상된 구조 AI다. 침상과 장치의 첫인상은 낯설지만, 자막은 감금·실험 대상·전투 임무로 단정하지 않는다. 외계 승무원이 공격해 오는 장면이나 AI가 위협하는 설명은 넣지 않는다.

## 10.5초의 시작 흐름

| 단계 | 기준 길이 | 화면과 동작 | 짧은 자막 예시 |
|---|---:|---|---|
| 눈뜨기 | 0~3초 | 누운 시점에서 구조 침상 주변이 드러난다. 처음부터 이동·점프를 받지 않는다. | 비상 기록: “네메시스 관측 항로… 추진기 응답 없음.” |
| 손바닥 문양 | 3~7초 | 구조 장갑의 빛나는 앵커를 보여준다. 이오의 구조 통신이 이어진다. | 이오: “여기는 아르카 구조동입니다. 손의 문양은 시간 앵커예요.” |
| 일어서기 | 7~10.5초 | 같은 방에서 정상 눈높이로 전환하고 출구가 열린다. | 이오: “천천히 일어나세요. 당신은 이제 안전합니다.” |
| 조작 시작 | 이후 | 구조실 z=-7 부근에서 자유롭게 살펴보고 걸어 나간다. | 목표: **구조동을 살펴보고 출구 찾기** / **Explore the rescue wing and find the exit** |

다음 보조 문구와 영문은 후속 대사·번역용 예시이며 현재 연출의 전체 자막과 구분한다.

> 주인공: “내 손에 이 문양은 뭐야?”
> 이오: “시간 앵커예요. 당신을 안정시키기 위해 연결했어요.”

영문 대응:

> Protagonist: “What is this mark on my hand?”
> Io: “A temporal anchor. It is keeping you stable.”

영문은 UI 제작·번역용 대응 원고다. 현재 게임에 언어 선택이나 영어판이 구현되었다는 뜻은 아니다. 이오 통신은 **자막과 짧은 합성음**으로 제시하며 AI 음성 연기·더빙이 있다고 안내하지 않는다.

## 건너뛰기와 조작 복귀

연출에는 **Space · 건너뛰기 / SKIP** 안내와 누를 수 있는 건너뛰기 버튼을 둔다. 어느 단계에서 건너뛰어도 **같은 구조실의 서 있는 시작 위치**로 정리한다. 로터 앞이나 방 바깥으로 순간 이동하지 않는다.

연출 중에는 이동·시점 회전·점프·시간 능력을 차단한다. 별도 필수 키 입력이나 시간 문을 추가하지 않는다. Esc 일시정지와 건너뛰기는 사용할 수 있어야 한다. 연출이 끝나면 카메라 자세·플레이어 위치·커서 잠금·입력 상태를 함께 정상화한다.

**이야기 시작**은 각성 연출을 재생한다. 플레이 도중 **처음부터 다시**는 연출을 반복하지 않고 구조실의 서 있는 위치에서 빠르게 재개한다. 선택해서 읽는 J 발견 기록에 자세한 조난·앵커 배경을 남기되 읽기를 출구 통과 조건으로 만들지 않는다.

## 시간·목표·접근성

- 연출 중에는 진행 중인 여정이 존재하되 자유 플레이 상태는 아니다. 일시정지와 재개는 연출의 남은 시간을 보존한다.
- 퍼즐 경과 시간은 **자유 조작이 시작된 뒤** 증가한다. 연출을 끝까지 보거나 바로 넘겨도 기록에 불이익이 없다.
- 첫 체크포인트는 구조실이다. 이후 기존 로터 통과 체크포인트 z=14 등은 유지한다.
- 구조실 출구는 x=-2~2, z=0의 통로를 통해 기존 복도로 연결한다. z=3 이전에는 탐색 목표, 이후에는 로터 정지 목표를 제시한다.
- **카메라 움직임 효과 끔**에서는 고정된 구도와 컷 전환으로 상황을 전달한다. 흔들림·누운 카메라의 강제 회전·일어서는 동안의 카메라 이동을 강요하지 않는다. 서 있는 최종 시점으로의 전환은 명확한 컷으로 처리한다.

## 우선 확인할 테스트

| 상황 | 기대 결과 |
|---|---|
| 새 이야기 시작 | 첫 시점이 누운 구조 침상이며 손바닥 앵커가 구별된다. |
| 첫 단계·문양 단계·일어서기 단계에서 각각 건너뛰기 | 같은 방의 서 있는 시작 위치, 정상 눈높이·입력으로 끝난다. 연출이 다시 카메라를 덮어쓰지 않는다. |
| 연출 중 Esc → 대기 → 재개 | 카메라·자막·단계 시간이 멈췄다가 같은 지점에서 이어진다. |
| 일시정지 상태에서 Space | 의도하지 않은 이동·점프나 연출 진행이 발생하지 않는다. |
| 연출 종료 또는 건너뛰기와 이동 키를 동시에 입력 | 바닥 낙하·침상 끼임·중복 초기화가 없다. 건너뛰기 Space가 즉시 점프로 이어지지 않는다. |
| 연출을 모두 보기 / 즉시 건너뛰기 비교 | 퍼즐 타이머는 모두 자유 조작 이후 시작한다. |
| 접근성 설정을 끄고 시작 / 연출 중 설정 변경 후 재개 | 강제 카메라 이동이 없고 최종 자세는 같다. |
| 창 포커스 상실 후 돌아오기 | 연출이 일시정지되며 커서·메뉴·입력 상태가 어긋나지 않는다. |
| 처음부터 다시 / 첫 체크포인트 복귀 | 구조실에서 서 있는 상태로 정상 재개한다. 이전 손 연출·자막이 남지 않는다. |
| z=-7 → 출구 z=0 → 복도 z=3 이동 | 방에서 복도로 실제로 걸어 나갈 수 있고 목표가 적절히 전환된다. |
| 출구를 넘지 않고 J 기록을 열고 닫기 | 게임 시간이 멈췄다가 원래 화면으로 복귀하며 기록 열람이 필수 진행 조건이 아니다. |
| 구조실에서 기존 로터·발전기·다리·에어록까지 진행 | 기존 퍼즐 성공 조건과 이후 체크포인트가 유지된다. |

눈뜨기 장면과 손바닥은 실제 카메라 렌더를 확인했다. 접근성 모드, 단계별 건너뛰기, 일시정지·이어하기와 방 출구부터 에어록까지의 이동은 자동 실행 검사로 확인했다. 위 표의 모든 하드웨어 동시 입력 상황을 사람이 직접 시험했다고 주장하지 않는다. 화면 제어는 사용자 Esc 입력으로 중단했다.
