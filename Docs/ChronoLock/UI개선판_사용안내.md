# CHRONO / LOCK · UI 개선판 사용 안내

타이틀·메뉴·설정·게임 화면 안내를 개선하고, 스토리에 맞는 구조실과 1인칭 각성 연출을 추가했습니다. 기존 세 시간 퍼즐의 순서는 유지합니다.

타이틀, 일시정지 메뉴, 네 가지 설정 탭, 단계별 힌트, 발견 기록과 HUD가 구현되어 있습니다. 실행 파일은 `Windows_최신판/ChronoLock.exe`입니다. 배포할 때는 해당 폴더 전체를 함께 보관하세요.

## 시작과 이어하기

타이틀에서 **이야기 시작**을 누르면 구조 침상에서 눈을 뜨고 손바닥 앵커를 확인한 뒤 일어납니다. 약 10.5초 뒤 같은 구조실에서 자유롭게 움직입니다. Space 또는 화면 버튼으로 건너뛰고 Esc로 연출도 일시정지할 수 있습니다. 메인 메뉴로 돌아가면 **같은 실행 동안에는 이어하기**로 중단한 장면에 복귀합니다. **배경 이야기**는 선택해서 읽는 설명입니다.

게임을 종료하면 진행 중인 여정은 저장되지 않습니다. 적용한 설정과 탈출 최고 기록은 이 PC에 저장됩니다.

Esc 메뉴에서 **계속하기**, **체크포인트에서 재개**, **설정**, **조작 안내**, **힌트**, **발견 기록**, **처음부터 다시**를 선택할 수 있습니다. 체크포인트 재개는 복구한 장치를 유지하고 안전한 위치로 돌아갑니다. **처음부터 다시**는 연출을 생략하고 구조실에서 재시작하며 **새 여정**은 각성부터 다시 재생합니다. 진행을 지우는 재시작과 종료는 확인창을 거칩니다. 다른 창으로 전환하면 자동으로 일시정지됩니다.

## 설정

| 탭 | 조절 항목 |
|---|---|
| 화면 | 창 / 테두리 없는 전체 화면, 그래픽 품질, 프레임 제한, 수직 동기화 |
| 조작 | 마우스 감도, 시야각, 상하 시점 반전 |
| 오디오 | 전체 음량, 효과음 음량 |
| 접근성 | 카메라 움직임 효과, 플레이 시간 표시 |

설정을 바꾼 뒤 **변경 적용**을 눌러야 실제로 반영·저장됩니다. 저장한 값은 다음 실행에서도 불러옵니다. 변경이 없으면 적용 버튼은 비활성화됩니다. 적용 전에 뒤로 나가면 변경을 버릴지 확인합니다. **기본값 복원**도 변경 적용을 눌러야 저장됩니다.

수직 동기화를 켜면 모니터 주사율이 프레임 제한보다 우선합니다. 카메라 움직임 효과를 끄면 걷기 흔들림·착지 반동·달리기 시야 변화와 손목 장치의 흔들림이 꺼집니다. 시작 연출도 고정 시점과 컷 전환으로 바뀝니다.

## 조작과 화면 안내

WASD 이동 · 마우스 시점 · Shift 달리기 · Space 점프

**1 / 2 / 3**으로 정지·가속·되감기를 고르고, 장치를 조준해 **좌클릭**으로 적용합니다. **우클릭**은 해제, **E**는 충전·복구 확정 또는 탈출입니다. **F1**은 조작 안내, **H**는 현재 목표 힌트, **J**는 발견 기록·구간 통신, **Esc**는 메뉴, 플레이 중 **R**은 처음부터 다시 시작할지 묻습니다.

메뉴는 마우스 또는 방향키·Enter로 조작합니다. Tab / Shift+Tab으로 항목을 이동할 수 있습니다. 게임 화면에는 현재 목표, 선택 능력, 조준 장치의 진행률과 다음 행동이 표시됩니다.

## 막혔을 때 힌트

플레이 중 **H** 또는 일시정지 메뉴의 **힌트**를 선택하세요. 현재 목표에 맞춰 단서부터 구체적인 해결 순서까지 세 단계로 공개됩니다. **다음 힌트 보기**로 필요한 만큼 확인할 수 있습니다.

힌트를 보는 동안 게임 시간은 멈춥니다. 플레이 중 열었다면 뒤로 가기로 바로 플레이에 복귀하고, 일시정지 메뉴에서 열었다면 해당 메뉴로 돌아갑니다.

## 검증 상태

연출·전체 탈출 경로·UI 자동 검증과 Windows 빌드가 통과했습니다. 자동 메뉴·상태 검증은 사람이 실제 키보드·마우스로 전체 탈출을 완료한 플레이테스트와 구분합니다. 자세한 범위와 증거는 [시작 연출 변경과 검증](시작연출_변경과_검증.md)을 참고하세요.
