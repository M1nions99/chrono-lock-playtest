# 게임 흐름 · UI/UX 다이어그램 사용 안내

게임흐름_비교와_UIUX.drawio는 편집 가능한 4페이지 문서입니다. draw.io에서 열고 하단 탭으로 전환하세요. 각 페이지의 SVG·PNG 미리보기를 함께 제공합니다.

1. 현재 구현 흐름: 실제 캡슐 각성, 구조실 탐색, 메뉴·퍼즐·기록·완료 정책.
2. 개선 전후 비교: 메뉴·설정·기록·실제 공간 도입의 개선과 후속 UI 과제.
3. 레퍼런스와 다음 실험: 관찰과 아직 구현하지 않은 확장 제안.
4. 스토리와 플레이 연결: 인물·앵커 규칙·현재 1막·후속 5장 구분.

## 최신 구현 반영
「이야기 시작」은 강제 텍스트 페이지가 아니라 약 10.5초의 실제 1인칭 캡슐 각성으로 연결됩니다. 눈 뜨기·손바닥 문양·이오 교신·기립 후 같은 구조실에서 탐색을 계속합니다. 배경 이야기 글은 선택 메뉴입니다.

Space나 건너뛰기를 누르면 즉시 같은 방에 서며, ESC 메뉴에서는 각성 연출 시간도 멈춥니다. 메인 메뉴의 이어하기는 미완료 각성을 이어갑니다. 새 여정은 각성부터 다시 시작하고, 빠른 재시작과 체크포인트는 각성 없이 재개합니다.

J 기록에는 발견 기록·구간 통신 탭이 있습니다. 「구조 요청의 끝」은 시작부터, 「손바닥의 앵커 / 비어 있는 방주 / 남겨진 구조 신호」는 회전 구역 통과·전력 확정·다리 복원으로 해제됩니다. 현재 완료는 1장 구조동 탈출과 귀환 경로 확보이며 실제 지구 귀환은 후속 이야기입니다. 43초 대피 기록은 현재 제한 시간이 아닙니다.

이어하기는 현재 실행에 한정됩니다. 종료 후 진행 복원과 키 재매핑은 미구현이며 후속 UI 검토 과제입니다. 옵션과 최고 기록은 로컬에 저장됩니다.

## 실제 MCP 검증
- 누락된 drawio-mcp-server 2.2.0을 기존 설정 경로에 복구했습니다. Codex 설정은 변경하지 않았습니다.
- 표준 MCP initialize·tools/list·list-documents 연결을 확인했습니다.
- create-page·import-diagram으로 실제 draw.io 편집기에 문서를 구성하고 export-diagram으로 편집 XML·SVG·PNG를 내보냈습니다.
- 최종 ChronoOpening·ChronoInterface·ChronoNarrative 소스를 읽어 1·2·4페이지를 동기화했습니다. 레퍼런스 페이지는 유지했습니다.
- 출력 파일의 4페이지와 PNG 가독성을 확인했습니다. 이 도표는 실제 키보드·마우스로 게임 전체를 검증했다는 주장이 아닙니다.
